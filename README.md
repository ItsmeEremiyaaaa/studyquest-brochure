# StudyQuest — Interactive Brochure

A 3D, flip-through version of the StudyQuest trifold brochure.

- Tap / click the brochure (or press →) to open the cover, unfold the flap and close it again
- **Flip over** (or press F) to see the back panel with the QR code
- Swipe left/right on phones
- **View in Canva** opens the design: https://canva.link/4h79qam975pfb7e
- **PDF** downloads the print-ready brochure (US Letter, landscape)

Play StudyQuest: https://studyquest-a547c.web.app

An app development project by BSIT students of St. Mary's College of Bansalan, Inc.
